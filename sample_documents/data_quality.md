# Data quality validation procedure
Fictional learning material. Not an employer policy.

Completeness measures whether required values are present. Uniqueness checks whether a business identifier appears more than once. Validity checks whether values follow approved formats and ranges. Consistency compares related values across sources. Timeliness checks whether records arrive by the agreed reporting cutoff.

For address records, verify required street, city, state, and postal code values, validate permitted state codes, and check postal code format. A format check does not prove that a physical address exists. Document suspected issues and send them to the Data Owner for confirmation before correction. Run validation before publishing a reporting dataset.
